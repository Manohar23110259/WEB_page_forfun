# WEB_page_forfun

A one-page night-sky site with a signature pad. Names and drawings are saved to a Supabase `signatures` table.

## Setup

```bash
npm install
cp .env.example .env.local
```

Fill in `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` in `.env.local`.

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
